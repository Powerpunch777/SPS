# Security Policy

SPS is in a private feedback beta.

Report a suspected vulnerability privately to
[redongames1234@gmail.com](mailto:redongames1234@gmail.com) with the subject
`SPS Security Report`.

Include the SPS Desktop version, affected feature, reproduction steps, and
impact. Share the minimum diagnostic material needed. Do not open a public
issue containing:

- passwords, OAuth data, API keys, tokens, or private signing keys;
- SPS invitation codes or Member/Node credentials;
- private project files, Workspace exports, or customer data;
- unredacted logs or screenshots containing personal information.

We will acknowledge useful reports and coordinate a safe disclosure timeline
when the issue is confirmed. The beta does not currently publish a guaranteed
response-time service level.
