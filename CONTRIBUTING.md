# Product Feedback

This repository is the public product overview for SPS. It does not contain
the SPS Core or Desktop source, so source-code pull requests are not accepted
here.

Public issues may be used for sanitized product feedback, documentation
corrections, feature requests, and reproducible beta bugs. Before posting:

1. Check that the issue does not expose credentials, invitation codes,
   account details, private project content, or unredacted logs.
2. Include the SPS Desktop version and Windows version.
3. Separate observed behavior from the result you expected.
4. Describe the smallest sequence that reproduces the problem.

Plugin SDK contributions belong in
[Powerpunch777/sps-plugin-sdk](https://github.com/Powerpunch777/sps-plugin-sdk).
Security reports must follow [SECURITY.md](SECURITY.md) and be sent privately.
